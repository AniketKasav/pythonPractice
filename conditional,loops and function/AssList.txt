Q27. Write a java program to Check If a Number Is a Happy Number or Not.
	Example : A number is called happy if it leads to 1 after a sequence of steps where in each step number is
	replaced by the sum of squares of its digit, that is if we start with Happy Number and 
	keep replacing it with digits square sum, we reach 1.
        	Input: n = 19
        	Output: True
        	19 is Happy Number,
        	1^2 + 9^2 = 82
        	8^2 + 2^2 = 68
        	6^2 + 8^2 = 100
        	1^2 + 0^2 + 0^2 = 1
        	As we reached 1, 19 is a Happy Number.
Q28. Write a java program to Check Number Is Spy Number or Not.

 	Input : 1412
	Output : Spy Number

	sum = (1 + 4 + 1 + 2) = 8
	product = (1 * 4 * 1 * 2) = 8
